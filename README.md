##  Описание проекта
Данный проект выполнен в рамках учебной практики и посвящен автоматизации бизнес-процессов компании, занимающейся оптовой продажей товаров. Основная задача — реализация бесшовной интеграции между CRM-системой (управление клиентами) и ERP-системой (планирование ресурсов и склад).

## 🛠 Выполненные задачи (согласно заданию)
В ходе работы были реализованы следующие этапы:
1. **Анализ предметной области:** Изучена структура оптовой компании и выявлена необходимость автоматизации передачи заказов из отдела продаж на склад.
2. **Проектирование интеграции:** Выбран архитектурный стиль **REST** и формат **JSON**, как наиболее эффективные для модульной архитектуры.
3. **Разработка модулей:**
    - `crm_module`: имитация захвата данных о клиенте и заказе.
    - `erp_module`: обработка входящих данных, резервирование товара на складе.
    - `validator`: модуль контроля качества кодирования и валидации входящих пакетов данных.
4. **Тестирование:** Проведена верификация программного обеспечения на соответствие функциональным требованиям и стандартам предприятия.

##  Технический стек
* **Язык разработки:** Python 3.10+
* **Архитектура:** Модульная (Loose Coupling)
* **Формат обмена данными:** JSON
* **Методология:** RESTful API имитация
